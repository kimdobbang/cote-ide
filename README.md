# Cote IDE — 백준 문제를 시험 환경처럼 푸는 코딩테스트 연습 IDE

**바로 쓰기: https://kimdobbang.github.io/cote-ide/**

## 왜 만들었나

코딩테스트는 대부분 프로그래머스 같은 **웹 IDE 시험 환경**에서 봅니다. 그런데 연습은 문제 수가 많은 **백준**으로 하는 경우가 많습니다.

백준으로만 연습하면 로컬 IDE(IntelliJ, VS Code)의 자동완성과 편의 기능에 익숙해져서, 막상 시험의 웹 IDE에서는 문제를 풀기가 어려웠습니다. 자동완성 없이 코드를 쓰고, 테스트 케이스를 직접 넣어 보고, 제한 시간 안에 제출하는 흐름이 낯설기 때문입니다.

그래서 **백준 문제를 프로그래머스 시험 환경처럼 풀 수 있는 웹 IDE**를 만들었습니다. 프로그래머스식 코딩테스트 연습과 백준 문제 풀이를 한곳에서 함께 할 수 있습니다.

## 시험 환경처럼

- **자동완성 없음:** 문법 색상, 들여쓰기, 괄호 짝만 있고 추천·자동완성은 꺼져 있습니다.
- **시험 화면 배치:** 왼쪽 문제 설명, 오른쪽 코드, 아래 실행 결과와 테스트 케이스가 있습니다.
- **`코드 실행` / `제출 후 채점하기`:** 결과를 "테스트를 통과하였습니다", "정확성: 100.0"처럼 시험 화면과 같은 형식으로 보여 줍니다.
- **시험 타이머:** 시간을 정해 두고 남은 시간을 보며 풉니다.
- **공식 문서 버튼:** 시험에서 허용되는 언어 공식 문서(Java·Python·MySQL)를 바로 엽니다.

## 두 가지 문제 방식

| 방식 | 이런 문제에 | 작성하는 코드 |
|---|---|---|
| **solution 함수** | 프로그래머스식 문제 | `solution()` 함수의 반환값으로 채점 (기본 코드는 테스트 케이스에 맞춰 자동 생성) |
| **표준 입출력** | 백준식 문제 | `main`에서 입력을 읽고 출력 |

## 백준 문제 가져오기

1. 백준 문제 페이지에서 ⌘A(전체 선택) → ⌘C(복사)
2. 상단 `백준 문제 붙여넣기`에 붙여넣기
3. 문제 설명이 채워지고 **예제가 테스트 케이스로** 들어갑니다. 바로 `제출 후 채점하기`로 예제를 채점할 수 있습니다.
4. 예제를 모두 통과하면 `코드 복사하고 백준 제출 페이지 열기`로 백준에 제출해 최종 정답 여부를 확인합니다.

## 지원 언어

- **Java** (주력) — 브라우저 안에서 컴파일·실행합니다. `BufferedReader`, `StringTokenizer`, `Scanner`, `printf`, 컬렉션, `Map.Entry`를 지원하고, `HashMap`·`HashSet`은 진짜 JDK와 같은 순서로 꺼내집니다.
- **Python 3**
- **SQL** — SQLite + MySQL 호환 함수 일부 (`DATE_FORMAT`, `IF`, `YEAR` 등)

설치나 서버 없이 **브라우저 안에서만** 실행됩니다. 작성한 코드와 메모는 그 브라우저에만 저장됩니다. 두 번째 방문부터는 실행 환경을 저장해 둔 것을 써서 빠르게 열리고, 인터넷이 끊겨도 동작합니다.

## 그 밖에

- **메모장:** 풀이 아이디어나 반례를 적어 두는 메모장입니다. 팝업으로 띄우거나 옆에 띄워 둘 수 있습니다.
- **로컬 버전:** 실제 JDK·Python으로 실행하고, 백준 번호만으로 문제를 불러오며, solved.ac 난이도 표시와 랜덤 문제 기능이 있는 버전도 별도로 있습니다.

## 알아 둘 점

- 프로그래머스·백준·solved.ac의 공식 서비스가 아니며, 각 서비스와 관련이 없는 개인 연습용 도구입니다.
- 브라우저용 Java는 아주 깊은 재귀(약 1만 단계 이상)를 처리하지 못합니다.
- 사용한 오픈소스와 수정 내용은 [NOTICE.md](NOTICE.md)에 있습니다.
